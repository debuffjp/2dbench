Every device makes the dataset more useful: phones, tablets, old laptops, Safari, Firefox. Run it, then tap Submit to add your results to the public dataset. No account needed: it sends the results, your device note and your browser's user agent, which are published as a public issue on GitHub (no IP or anything else is kept). Prefer your own GitHub account? Use Submit on GitHub. Runs every 2D renderer in 2dbench on this device, in turn. Keep the screen on and this tab in front. Plug in if you can. It takes a few minutes.
