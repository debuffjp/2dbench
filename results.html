2dbench
Run Results GitHub

An open, fair benchmark for 2D web renderers

The same scenes and simulation for every library, a pixel-parity check before anything is timed, and every result published with its full environment. Compare libraries within one device: absolute numbers depend on the hardware, the browser and the day.

Is your device missing? Phones, tablets, Chromebooks, older laptops, Safari and Firefox are all wanted. Run it on this device: it takes a few minutes, needs no account, and your results land here once checked.
