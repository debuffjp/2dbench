Benchmark 2D web renderers on this device

Every device makes the dataset more useful: phones, tablets, old laptops, Safari, Firefox. Each renderer draws the same scenes with more and more sprites until it can't hold 60 fps. It takes a few minutes; keep the screen on and this tab in front, and plug in if you can.

Add them to the public dataset.

No account needed: Submit sends the results, your device note and your browser's user agent, published as a public issue on GitHub (no IP or anything else is kept). Prefer your own GitHub account? Use Submit on GitHub.
